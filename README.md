# 🧭 Ngulik Navbar

Repositori ini dibuat untuk mempelajari, meriset, dan mengimplementasikan berbagai jenis **Navigation Bar (Navbar)** modern, responsif, dan interaktif dalam pengembangan web.

---

## 📖 Apa itu Navbar?

**Navbar** (_Navigation Bar_) adalah area atau panel navigasi utama yang biasanya terletak di bagian paling atas halaman web atau aplikasi. Fungsi utamanya adalah sebagai panduan atau navigasi cepat bagi pengguna untuk berpindah antar halaman atau fitur tanpa tersesat.

---

## 🛠️ Anatomi & Komponen Utama

Sebuah navbar yang ideal umumnya terdiri dari beberapa elemen penting:

1. **Brand / Logo:** Terletak di sebelah kiri, berfungsi sebagai identitas situs sekaligus tautan kembali ke halaman utama (_Home_).
2. **Nav Links:** Tautan navigasi ke halaman-halaman utama (seperti _Home, About, Services, Contact_).
3. **Call to Action (CTA):** Tombol aksi khusus untuk mengarahkan pengguna (_Login, Register, Get Started_).
4. **Utilities & Search:** Fitur tambahan seperti pencarian cepat, keranjang belanja, atau tombol pengubah mode (_Dark/Light Mode_).
5. **Responsive / Hamburger Menu:** Tampilan menu ringkas (biasanya ikon garis tiga) pada layar ponsel untuk menghemat ruang.

---

## 🎨 Jenis Layout Navbar

| Jenis Navbar           | Deskripsi & Karakteristik                                                 |
| :--------------------- | :------------------------------------------------------------------------ |
| **Standard / Static**  | Menempel di paling atas halaman dan ikut tergulung saat di-_scroll_.      |
| **Sticky / Fixed Top** | Tetap melayang di atas layar saat halaman di-_scroll_ ke bawah.           |
| **Floating Navbar**    | Memiliki jarak (_margin_) dari tepi layar, tampak melayang seperti pulau. |
| **Sidebar / Vertical** | Navigasi berbentuk kolom vertikal di sebelah kiri atau kanan layar.       |
| **Glassmorphism**      | Transparan dengan efek buram (_blur/backdrop-filter_) modern.             |
